КАК ДОБАВИТЬ ФОТОГРАФИИ КВАРТИРЫ
================================

1. Складывайте фотографии (.jpg / .png / .webp) в папку своей квартиры
   внутри img\<id-квартиры>. Пример: img\gorkogo-1-2rooms

2. ПОРЯДОК ФОТО = ИМЯ ФАЙЛА. Первым показывается файл с именем 01...
   Пример хороших имён:
     01-гостиная.jpg
     02-спальня.jpg
     03-кухня.jpg
     04-ванная.jpg

3. После того как сложили фото — запустите двойным кликом:
     add-photos.bat
   Список фото обновится, обновите страницу в браузере (F5) — готово.

Первая фотография (01-...) будет обложкой карточки на главной странице.

Фото занимает место: если файлы большие (5-10 МБ), сайт грузится медленно.
Желательно, чтобы фото были примерно 1600 пикселей по ширине.
